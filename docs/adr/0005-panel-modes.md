# 三种形态合并为同一个面板的三种模式

面板顶部放一个三档切换：专注（A）、待办（B）、对话（C），当前模式记在 localStorage，下次打开保持上次选择。三种形态共享同一份快照（`companion:snapshot`）与同一套决策 IPC（`companion:decide`），只是渲染不同。

此前的 ADR-0004 把三种形态分给桌宠、面板与独立会话窗口，实测后用户认为多入口本身增加了理解成本，要求合并。原先的桌宠气泡与独立会话窗口随之删除：一个客户端只保留一个可切换的窗口。

## Consequences

- 面板是唯一入口；托盘不再有「对话」项，桌面上也不再浮气泡。
- 模式是纯前端状态，不进入快照，也不影响数据面（ADR-0002 不变）。
- 三个模式的渲染共用 `view`，但各自维护局部状态（对话记录只在内存，重启即清空）。
- 代价：A 与 C 的代码住在 `panel.js` 里，文件继续变长；后续若继续加模式，需要考虑把渲染拆成独立模块。
