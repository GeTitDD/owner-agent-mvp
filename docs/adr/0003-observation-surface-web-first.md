# 观察台先做 Web，桌面只做壳

v0.1 的验收指标（10 秒内定位最危险项目、误报率低于 20%）只能通过观察台验证，而 Electron 层是本仓库最薄弱的一环：没有单测、有 13 次渲染进程崩溃记录、打包产物从未运行、10 个桌面 E2E 脚本都在 CI 之外。把验收压在这一层，等于把「能不能交付」交给唯一无法自动验证的组件。

因此观察台作为一个普通 HTTP 路由挂在现有 workbench server 上，桌面端只用 `loadURL` 打开它。数据层（探针 → 事件 → 视图模型）是纯函数，用 node 测试覆盖；Electron 崩溃时观察台照常可用。

## Consequences

- 观察台的迭代不需要重启 Electron，也不需要 GUI 环境。
- 桌面客户端降级为可选入口；「桌面为主」的含义变成「桌面是默认打开方式」，而不是「唯一实现」。
- 如果将来要做托盘角标、原生通知，仍需补桌面层冒烟测试，但不阻塞 v0.1 验收。
