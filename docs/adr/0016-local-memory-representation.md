# 本机记忆的读写表示与跨设备冲突裁决分开

ADR-0002 的单一事实归属原则应继续保留，但其「人工内容归属 Markdown、机器事实归属 SQLite」的表示分工已经偏离个人知识工作台与同步模块的实现。本草案建议明确本机记忆的当前内容及修订由 SQLite 统一读写，Markdown 是供预览、同步与携带的文档投影；跨设备仍按 ADR-0013 先拉后推、冲突交人，不指定任何设备或远端永久优先。

这意味着选择事务、修订和现有审核链路的一致性，代价是外部手改 Markdown 不能不经检查就改变本机记忆。另一方案是恢复 Markdown 为本机人工记忆的权威表示，但需要重新定义现有审核事务、修订历史及恢复方式，不能靠同时写两份来解决。

## 状态与证据

本草案记录可审阅的方案，**尚未接受**，不构成新授权或迁移计划。贡献指南要求存储归属的方向改动先在 issue 中讨论；现有 #103、#130 只明确文档同步与冲突裁决，未完整决定本机表示分工，本轮没有代替用户向 issue 发布新决定。

现状可核对：`src/personal-store.mjs` 的内容与修订写入、`src/memory/sync-documents.mjs` 的文档投影、`src/memory/sync-service.mjs` 的确认后导入。将来接受此方案时需在 issue 记录理由、更新本草案状态并明确其取代 ADR-0002 的哪一部分；若选择恢复 Markdown 权威，则另行设计迁移与回滚验收。
