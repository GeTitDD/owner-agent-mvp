# 第七批：命令与技能可发现、身份明确、失败可恢复

日期：2026-11-27。整体目标继续进行，本批不是功能全部完成的声明。

## 旅程与结果

输入 `/`，按名字或说明查找命令/技能，核对来源，再填入命令或选中技能胶囊、补充问题后明确发送。
参数命令「记灵感」已进入目录，未填写内容时不写库、不产生半条失败回执。
菜单选择命令只填入，包括「发布确认」；直接手输完整命令后 Enter 仍按原语义明确执行。

`/记忆同步`、`/同步` 和 `/sync` 都进入真实记忆同步设置，检查与外发确认仍走第六批的真实流程。
旧的写入后外发演示改名为 `/样例同步`，不再拦截自然同步入口。

技能显示与模型调用现在共用完整来源身份：域包、pstack、matt、插件均通过同一登记结果进入只读对话。
同名技能可在行内按来源/分类区分，胶囊保留来源；完整 ID 精确选择，重复短名不会猜测第一项。
插件身份改为目录而非声明序号，重排清单不会悄悄换正文；重复身份指向不同文件时明确禁用。
旧插件序号身份不能安全还原来源，旧草稿遇到它时要求重选，不擅自迁移到另一技能。

缺失、空正文、不可读和 Playbook-only 条目仍在目录中显示原因，但不占数字快捷，也不能作为对话技能调用。
技能在选择后被移除时，后端再次核对，不请求模型；原问题留在会话中，可取回编辑。
技能只作为只读模型上下文，不安装扩展、不注册写入/执行/网络工具；原有只读工具二次校验保留。

修改快捷键使用交换，不再制造新重复。旧版本保存的重复数字会提示并阻止默认调用；
可以点具体条目、方向键明确选择、重新分配或恢复默认。修改后的映射跨重启保留。
目录失败有原位重试，空目录仍可用内置命令；刷新保留草稿与已选身份，慢响应不覆盖另一会话。
配置的 pstack / matt 路径现在确实用于扫描和调用，优先于环境默认路径。
