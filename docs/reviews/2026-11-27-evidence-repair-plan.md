# 经验可信度与引用计量修复计划

用户旅程：整理灵感或提炼执行记录 → 核对来源、证据与复现标记 → 提问并得到资料引用 → 在工作台区分已完成对话的引用记录与任务复用、收益。

成功条件：复制灵感不能成为复现；独立执行仍能支持复现；历史错误徽章在读取时纠正，保留原始来源。归档或取代证据不能继续提供当前事实支持；显式升域不提高可信度。

引用计量：只有成功完成、实际提供了资料的对话才计入“完成对话引用”；按本轮标识、来源 ID 和修订去重。只检索、资料因容量未注入、未配置模型、失败或取消均不增加这一保守计数。记录不声称模型采纳、不产生收益判断、不参与自动知识升级。

状态：零引用给出空态；运行中不提前记成功引用；成功显示记录说明；计量保存失败不丢回答、明确提示未保存；取消与失败保留既有恢复路径。验收覆盖新会话、跨项目只读关联、重启、长中文、错误态和深浅色。

架构文档：核对现有 issue 与 ADR，只澄清当前实现与历史分歧，不在未讨论时改动存储归属或同步冲突政策。

验证：先运行会失败的误标回归，再做针对性存储/对话/同步测试；最后全量测试、语法检查、真实 Electron 与工作台视觉验收。隔离数据库、本机模型夹具，不追加真实模型调用，不修改被观察项目。
