# 真实经验沉淀与复用修复

日期：2026-11-27。对应 `2026-11-27-real-project-dogfood.md` 的 R01–R06；整体持续迭代目标仍在进行。

## 已完成的用户旅程

`/记灵感` 粘贴真实观察 → 回执「整理经验」打开只读预览 → 补全现象、机制、对策并第一次确认 → 在同一流内审阅知识正文、适用条件、例外和项目/领域范围 → 第二次确认 → 新会话引用、同领域复用、关联经验生成 prompt → 重启恢复。

「打开整理」不写经验；第一次确认写经验并准备待审候选，第二次确认才写正式知识。准备候选不再要求一次额外的实质批准。
`取消`不写经验；`暂不沉淀`不写知识，已经保存的经验和候选保留。人的确认不会把推断或待验证自动变成已验证。

## 改动与原问题对应

| 原问题 | 修复 |
| --- | --- |
| R01 新会话未带入知识 | `src/knowledge/recall.mjs` 统一只读召回；普通聊天按本次冻结的项目和显式关联取资料，实际提示包含条目 ID、修订、状态、范围、全文与证据引用。回复下方显示同一轮实际引用，未命中明确说明。 |
| R02 正文被标题截断 | 灵感经验单独保留正文；短现象只作为标题。提升时合成正文与人工补齐的机制/对策。旧灵感经验可从原始记录恢复正文；旧待审候选可在编辑框恢复并让人核对后接受。已接受的旧知识不被后台改写。 |
| R03 无法流内改写/选范围 | 经验与候选表单都在对话流；候选可改标题、正文、适用条件、例外，并明确选项目或领域。正文和范围由后台校验；不能顺便改证据来源、验证状态或其他隐藏字段。 |
| R04 `/经验` 漏掉领域正式知识 | 显式查询、普通提问和关联经验使用同一召回口径。正式知识优先于它对应的旧经验，避免一条事实重复变成两条建议。 |
| R05 关联只有路径 | `@@` 选中的经验读取为实际引用；生成 prompt 带正文、ID/修订、来源与状态，不再只给项目路径。普通聊天也接收发送时冻结的关联 ID，不靠正文里的路径猜读取范围。 |
| R06 新项目没有提炼原料时走入死路 | 空态说明只处理本应用终态执行记录，Git/聊天不冒充执行证据；明确指向 `/记灵感` 手动整理原文。没有原料仍不调用模型。 |

保留已有的接受/拒绝状态机。接受操作在同一个 SQLite 事务内检查候选展示版本、来源经验与目标修订，再保存**实际改写后的正文和范围**。
候选已被其他操作改变、来源已被取代/归档，或目标修订变化时拒绝旧确认；不消耗按钮、不清输入。旧卡先打开最新审阅，不盲批旧快照。

项目专用记录只进入本项目；领域共享只进入匹配领域。显式关联是带标识的只读参考，不把事实复制到另一个项目。
争议条目明确标注、排序靠后；已取代记录和归档条目不作为当前正常建议。知识引用不授予执行、写入或额外联网权限。

## 草稿与视觉验收

审阅表单草稿落在本机 `owner_review_drafts`，按会话、卡片身份和审阅版本隔离；不参与记忆同步。
实际验收发现 localStorage 在快速退出后不足以可靠恢复，因此改为 SQLite。重载、退出再启动、候选过期以及保存失败后，中文多行输入仍保留。
成功或取消时清除对应草稿；来源版本不同不会套用旧稿。软删除会话不能继续写审阅草稿。

已打开检查实际截图，并修复本轮发现的表现问题：

- 表单与引用保留完整中文边界，不以标题替代正文；证据默认折叠，正文在审阅区可编辑。
- 长项目名显示来源信息，范围在确认前可见；字段缺失在原位给中文原因，避免 Electron 通道名淹没提示。
- 审阅动作清除上一动作残留的浮层提示，错误保留在本表单；提示条避开整个关联/输入区。
- 生成的中文 prompt 自动换行便于审核，普通源码块仍保留横向滚动。
- 工作台长标题不再把验证徽章挤成竖排。只在旧实验数据库副本中为视觉检查保存 r3，原实验 r2 未改动。
- 核对浅色/深色、长中文、过期错误、重启恢复、关联资料与领域选择；macOS 验收不代表 Windows 已验收。

## 仍有的边界

- 自动蒸馏仍只处理应用的终态执行记录；本次真实项目没有此类原料，未追加宣称自动蒸馏质量通过。外部提交和日志通过显式手动整理进入经验，不后台扫描或伪造执行。
- 召回是本机中文分词与关键词匹配，不是任意表述的语义检索。引用容量有限，过长正文明确列为未注入，不截半条结论当完整依据。
- 经验正文首次整理上限 16000 字、知识正文 20000 字；适用条件和例外分别最多 1000 字。超过会拒绝并保留输入。
- 不自动改写已接受的历史知识；需要通过人工修订保留历史。原始灵感已不存在时，旧经验可能只剩证据摘录，需要人核对原记录并补齐。
- 本轮打通关联的经验/知识正文，图谱、画像和外部会话的完整资料解析没有一起扩张。
- Windows、真实提供商的新回答质量、真实跨设备 GitHub 同步、超大知识库性能仍待独立验收；这些没有被本批状态替换成完成。
