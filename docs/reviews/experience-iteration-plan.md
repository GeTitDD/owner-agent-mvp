## 第七批旅程与成功条件

第七批：输入 `/` → 按意图搜索 → 看清命令/技能、来源和不可用原因 → 填入命令或选择技能 → 补充问题并明确发送。

四处来源使用相同完整身份，同名条目不靠顺序猜测；不可用条目保留原因，不占数字快捷，不得静默当普通问题回答。
新快捷分配一对一交换，旧冲突默认调用被拦；目录刷新、迟到响应、切换会话与重启不覆盖输入。

实际验证：真实 Electron / IPC / SQLite / 已安装 SDK；本机 HTTP/SSE 返回固定模型输出，检查当前请求的身份与正文。
目录正常扫描使用实际配置与磁盘；失败/延迟和空根目录由隔离宿主注入，不读取个人凭据或收费模型。
整体目标继续进行，Windows 真机、真实提供商与超长技能全文注入尚未覆盖。
