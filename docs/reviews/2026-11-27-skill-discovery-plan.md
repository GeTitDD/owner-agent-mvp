# 第七批：命令与技能发现

旅程：输入 `/` → 按意图搜索命令或技能 → 看清来源/不可用原因 → 填入命令或选择技能 → 补充内容并明确发送 → 原会话得到真实结果。
数字修改不能产生新的重复分配；旧重复分配不能默认选择第一项。同名技能必须使用稳定完整身份。
命令目录不依赖文件扫描成功，技能目录加载失败要能原位重试；刷新不得覆盖输入、草稿、已选技能或另一会话。

成功条件：记灵感等参数命令可发现且只填入不发送；发布确认不能由一次菜单点击执行；
四处目录与只读后端使用同一身份，缺失/空正文/Playbook-only 保留但不可调用；
真实 SDK + 本机模型协议收到选定技能正文，不把另一个同名来源带入。

状态与验收：命令可用但技能加载中、目录空/失败/重试、无匹配、不可用说明、快捷交换/旧冲突、技能已移除、
发送成功、取消、重启与跨会话草稿；真实 Electron、长中文、深浅色截图与相关回归。无个人凭据、收费模型或个人仓库写入。
